# Lagom Ceramics — лендинг гончарной мастерской

Одностраничный сайт для мастерской Маши (Instagram [@lagom_ceramics](https://www.instagram.com/lagom_ceramics/)): мастер-классы по керамике у м. Белорусская и посуда ручной работы в наличии.

## Структура

```
index.html            — страница (10 блоков, разметка Schema.org, Open Graph)
css/style.css         — стили
js/main.js            — меню, подборщик мастер-класса, корзинка, слайдер отзывов, ленивая карта
img/                  — фото в WebP + JPG (два размера: -sm 480px и 960px), og-image.jpg
favicon.svg, favicon-32.png, apple-touch-icon.png, icon-192.png, icon-512.png
site.webmanifest      — манифест для «Добавить на экран»
robots.txt            — правила для поисковиков и AI-ботов
sitemap.xml           — карта сайта с изображениями
llms.txt              — краткое описание для AI-поиска (GEO)
```

## Блоки

1. Первый экран — вордмарк «lagom» с чашкой вместо «o», оффер, быстрые факты.
2. Подборщик мастер-класса — формат, число гостей, день; считает сумму и копирует готовый текст заявки в директ.
3. Путь изделия — от лепки до второго обжига, шкала 1230°.
4. Почему уютно — преимущества в виде переписки.
5. Посуда в наличии — 9 изделий с кнопкой «Отложить» и корзинкой, которая собирает заказ одним сообщением.
6. Работы гостей — галерея.
7. О Маше — фото, философия lagom, ссылки на Telegram и Instagram.
8. Отзывы — слайдер (свайп, стрелки, точки, клавиатура).
9. Частые вопросы — аккордеон (дублируется в FAQPage для поиска).
10. Адрес и карта — Яндекс Карта (грузится при прокрутке), режим работы.

## Перед публикацией

- Заменить домен `https://lagom-ceramics.ru/` на реальный: `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`, `llms.txt`.
- Отзывы в блоке 8 — демонстрационные, заменить на реальные из директа/сторис клиента.
- Уточнить у Маши: цены мастер-классов указаны за одного человека; лимит гостей на росписи в подборщике стоит 8 (`js/main.js`, объект `CLASSES`).
- Запись и заказ идут в директ Instagram (`ig.me/m/lagom_ceramics`). Если удобнее Telegram — заменить константу `IG_DM` в `js/main.js`.
- Шрифты Unbounded и Golos Text подключены через Google Fonts.

Сайт статический: достаточно залить папку на любой хостинг (Timeweb, Beget, REG.RU, GitHub Pages, Netlify). Проверено в Chromium на десктопе и мобильном экране 390px; вёрстка рассчитана на Safari iOS 14+, Chrome, Firefox, Яндекс Браузер, Samsung Internet.
